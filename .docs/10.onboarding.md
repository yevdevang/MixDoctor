# Feature Request: Onboarding Tour for MixDoctor

## Context

MixDoctor is an iOS/iPadOS/macOS audio mix analysis app built with SwiftUI. Users can upload audio files, get AI-powered analysis, and receive specific mixing recommendations. The app has a freemium model: 3 free analyses, then users must subscribe (3-day trial → $7.99/month or $69.99/year).

### Current Problem
- 27 downloads but only 12 users actually opened and used the app (44% activation rate)
- Users who download don't know what to do first
- No guidance on first launch
- Users may not have audio files ready
- Empty dashboard state is confusing for new users

### Goal
Implement a first-launch onboarding tour to improve activation rate from 44% to 70-80%.

---

## Requirements

### User Flow
1. User opens app for the first time
2. Show onboarding tour (3 screens with smooth transitions)
3. User can navigate through screens or skip anytime
4. Store completion flag so tour doesn't show again
5. User proceeds to main app dashboard

### Technical Requirements
- Built with SwiftUI
- Only shown on first launch
- Store completion state in AppStorage
- Skip-able (user can dismiss anytime via "Skip" button)
- Smooth page transitions with TabView
- Page indicator dots at bottom
- Clean, modern design matching app aesthetic (purple accent color)
- Support for iOS, iPadOS, and macOS (Catalyst)
- Light and dark mode support
- Dynamic Type support for accessibility

Modify the main app entry point (probably `MixDoctorApp.swift` or main view):

```swift
import SwiftUI

struct MixDoctorApp: App {
    @AppStorage("hasCompletedOnboarding") private var hasCompletedOnboarding = false
    
    var body: some Scene {
        WindowGroup {
            if !hasCompletedOnboarding {
                OnboardingView(isPresented: $hasCompletedOnboarding)
            } else {
                MainAppView()  // Your existing main view
            }
        }
    }
}
```

## Code Structure & Examples

### OnboardingView.swift (Main Container)

```swift
import SwiftUI

struct OnboardingView: View {
    @Binding var isPresented: Bool
    @State private var currentPage = 0
    
    var body: some View {
        ZStack {
            // Main content with TabView for pagination
            TabView(selection: $currentPage) {
                OnboardingWelcomeScreen(currentPage: $currentPage)
                    .tag(0)
                
                OnboardingHowItWorksScreen(currentPage: $currentPage)
                    .tag(1)
                
                OnboardingFreeTrialScreen(isPresented: $isPresented)
                    .tag(2)
            }
            .tabViewStyle(.page)
            .indexViewStyle(.page(backgroundDisplayMode: .always))
            
            // Skip button overlay (top-right)
            VStack {
                HStack {
                    Spacer()
                    Button("Skip") {
                        withAnimation {
                            isPresented = false
                        }
                    }
                    .foregroundColor(.secondary)
                    .padding()
                }
                Spacer()
            }
        }
    }
}
```

### OnboardingHowItWorksScreen.swift (Screen 2)

```swift
import SwiftUI

struct OnboardingHowItWorksScreen: View {
    @Binding var currentPage: Int
    
    var body: some View {
        VStack(spacing: 32) {
            Spacer()
            
            // Title
            Text("How It Works")
                .font(.largeTitle)
                .bold()
                .padding(.bottom, 16)
            
            // Step 1
            OnboardingStep(
                icon: "arrow.up.doc.fill",
                title: "Upload Your Mix",
                description: "Import or record audio files"
            )
            
            // Step 2
            OnboardingStep(
                icon: "brain.head.profile",
                title: "Get AI Analysis",
                description: "Powered by Claude AI"
            )
            
            // Step 3
            OnboardingStep(
                icon: "waveform",
                title: "Improve Your Sound",
                description: "Follow specific recommendations"
            )
            
            Spacer()
            
            // Next button
            OnboardingButton(title: "Next") {
                withAnimation {
                    currentPage = 2
                }
            }
            .padding(.horizontal, 40)
            .padding(.bottom, 60)
        }
        .padding(.horizontal, 40)
    }
}

// Helper view for each step
struct OnboardingStep: View {
    let icon: String
    let title: String
    let description: String
    
    var body: some View {
        HStack(alignment: .top, spacing: 16) {
            Image(systemName: icon)
                .font(.system(size: 32))
                .foregroundStyle(.purple)
                .frame(width: 40)
            
            VStack(alignment: .leading, spacing: 4) {
                Text(title)
                    .font(.headline)
                
                Text(description)
                    .font(.subheadline)
                    .foregroundColor(.secondary)
            }
            
            Spacer()
        }
    }
}
```

## Design Specifications

### Colors
- **Primary accent:** Purple (match app branding)

- **Step description:** `.subheadline`, regular

- **Screen padding:** 40pt horizontal
- **Element spacing:** 24pt between major elements
- **Button height:** 50pt minimum (for accessibility)
- **Bottom padding:** 60pt (above safe area)

- **Icons (large):** 100pt (screen 1 & 3)

- **Button corner radius:** 12pt

### Animations
- **Page transitions:** Smooth horizontal slide (default TabView)
- **Skip button:** Fade animation when dismissing
- **Button tap:** Scale effect on button press (optional)

## AppStorage Implementation

### Key Name
```swift
@AppStorage("hasCompletedOnboarding") private var hasCompletedOnboarding = false
```

### When to Set to `true`
- User completes all 3 screens and taps "Get Started"
- User taps "Skip" button at any point

### Persistence
- Stored in UserDefaults
- Persists across app launches
- Reset only when app is deleted and reinstalled

## Accessibility

### Dynamic Type
- All text uses system fonts that scale with Dynamic Type
- Test with larger text sizes (Settings → Accessibility → Larger Text)

### VoiceOver
- All buttons have clear labels
- SF Symbols should have `.accessibilityLabel()` if meaning isn't clear
- Page indicators announce current page

### Tap Targets
- All buttons minimum 44pt x 44pt
- "Skip" button should be at least 44pt tappable area

### Color Contrast
- Ensure text meets WCAG AA standards (4.5:1 contrast ratio)
- Test in both light and dark mode

## Testing Scenarios

### Test Cases
1. **First launch**
   - Open app for first time
   - Onboarding should appear
   - Navigate through all 3 screens
   - Tap "Get Started"
   - Should see main app
   - `hasCompletedOnboarding` should be `true`

2. **Skip functionality**
   - Open app for first time
   - Tap "Skip" on screen 1, 2, or 3
   - Should immediately show main app
   - `hasCompletedOnboarding` should be `true`

3. **Persistence**
   - Complete onboarding
   - Close app completely
   - Reopen app
   - Should NOT show onboarding again
   - Should go directly to main app

4. **Reset (testing)**
   - Delete app
   - Reinstall app
   - Open app
   - Onboarding should appear again

5. **Platform compatibility**
   - Test on iPhone (various sizes)
   - Test on iPad
   - Test on Mac (Catalyst)
   - Ensure layout adapts properly

6. **Appearance modes**
   - Test in light mode
   - Test in dark mode
   - Ensure colors and contrast work in both

    }
}
#endif

## Optional Enhancement: Demo Audio Analysis

### Context
Some users may not have audio files ready when they first open the app. Provide a demo analysis so users can immediately see the value.

### Requirements
1. On the final onboarding screen, add a secondary button: "Try Demo"
2. When tapped, show a pre-loaded analysis result screen
3. Display mock data: Score 88, with sample recommendations
4. After viewing, prompt: "Now try with your own audio!"
5. This doesn't count toward the 3 free analyses

### Implementation
```swift
// On OnboardingFreeTrialScreen.swift
VStack {
    OnboardingButton(title: "Get Started") {
        isPresented = false
    }
    
    Button("Try Demo") {
        showDemoAnalysis = true
    }
    .foregroundColor(.purple)
}
```

### Demo Data
```swift
struct MockAnalysisResult {
    static let demo = AnalysisResult(
        score: 88,
        recommendations: [
            "Excellent stereo width in the high frequencies",
            "Consider reducing 200-400Hz by 2dB to reduce muddiness",
            "Overall dynamic range is well-balanced"
        ]
    )
}
```

### Benefits
- Users see value immediately
- No friction (don't need audio files ready)
- Demonstrates the app's core feature
- Increases likelihood of continued usage
